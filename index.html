Tentang Saya

Profil Singkat

Saya adalah pelajar SMK jurusan Teknik Jaringan Komputer dan Telekomunikasi (TJKT) yang memiliki antusiasme tinggi di bidang administrasi jaringan, Linux Server, Fiber Optik, dan keamanan siber dasar. Terbiasa melakukan konfigurasi perangkat keras jaringan serta troubleshooting konektivitas.

Keahlian Teknis

Routing & Switching

Konfigurasi MikroTik (MTCNA), Cisco Packet Tracer, VLAN, OSPF, dan Manajemen Bandwidth.

System Administration

Instalasi & konfigurasi Linux Debian/Ubuntu Server (DNS, DHCP, Web Server, Mail Server).

Fiber Optik (FTTH)

Penyambungan kabel FO (Splicing), pengukuran redaman dengan OTDR & OPM, instalasi ODP/ONT.

Network Security

Konfigurasi Firewall, VPN (PPTP/L2TP/WireGuard), serta pemantauan trafik jaringan.

Proyek & Praktikum

MikroTik

Hotspot Voucher & Load Balancing

Membangun sistem RT/RW Net skala lab menggunakan metode Load Balancing PCC 2 ISP dan manajemen user dengan Mikhmon.

Linux Server

Web Hosting & DNS Server Lokal

Implementasi Debian 11 Server menggunakan Nginx, MariaDB, Bind9, dan sertifikat SSL lokal untuk layanan intranet sekolah.

Fiber Optik

Instalasi Jaringan FTTH

Simulasi penarikan kabel dropcore dari ODP ke OTP, melakukan fusion splicing, dan memastikan redaman di bawah -20 dBm.

MikroTik

Segmentasi Jaringan dengan VLAN

Memisahkan trafik jaringan Guru, Siswa, dan Tamu menggunakan Router-on-a-Stick dan Manageable Switch.

Sertifikasi & Informasi Tambahan

Sertifikasi MTCNA

MikroTik Certified Network Associate - Menguasai dasar routing, firewall, wireless, dan QoS.
